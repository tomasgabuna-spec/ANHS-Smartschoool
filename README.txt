ANHS SmartSchool - Role-Based Access

Demo accounts:
Admin: admin / admin123
Department Head: depthead / depthead123
Teacher: adviser1 / adviser123
Teacher: adviser2 / adviser123

Teachers can only upload and view their own submitted lesson plans. Admin and Department Head can view all uploaded files and assign the checker.

Important: This is a front-end demo. Real privacy/security requires server-side authentication and authorization with a database/storage layer.
